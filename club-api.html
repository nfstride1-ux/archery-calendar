Club events API

For clubs that keep their events in their own software. Send each event to us as you enter it, and it shows on archerycalendars.com within a minute. Change it later and the calendar updates. Delete it and it's gone.

No software to connect? Signed-in clubs can also upload a spreadsheet: see Bulk upload.

Getting a key: email nfshold@gmail.com. Each club gets its own private key. A key can only add, change or remove that club's own events, nothing else on the site. Keep it secret, like a password. If it ever leaks, tell us and we'll switch it off straight away and send a new one.

1. The address

https://sllsqpfqwckwtljzjxli.supabase.co/functions/v1/club-events

Send your key in a header on every call:

X-Api-Key: YOUR_CLUB_KEY

2. Add or update events

POST JSON with Content-Type: application/json. Send one event or up to 50 at a time.

curl -X POST https://sllsqpfqwckwtljzjxli.supabase.co/functions/v1/club-events \
  -H "X-Api-Key: YOUR_CLUB_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "events": [{
    "id": "2027-field-champs",
    "title": "Club Field Championships",
    "start_date": "2027-03-14",
    "end_date": "2027-03-14",
    "start_time": "8:30am assembly, 9:00am shooting",
    "venue": "Club range, 1 Example Road, Sometown SA",
    "shoot_type": "Field",
    "entry_method": "archers_diary",
    "entry_link": "https://archersdiary.com/...",
    "entry_close_date": "2027-03-07",
    "rounds": "2 x 28 target field",
    "notes": "BBQ lunch available.",
    "flyer_url": "https://yourclub.example/flyers/field-champs.pdf"
  }]
}'

Updates: the id is your own id for the event (from your software). Send the same id again with the new details and we replace the old version, so there are never duplicates. Always send the full event, not just the changed fields.

3. The fields

FieldNeeded?What to send
idYesYour own id for the event. 1–64 letters, numbers, . _ : -
titleYesEvent name, up to 140 characters
start_dateYesYYYY-MM-DD
end_dateNoYYYY-MM-DD. Leave out for one-day events
start_timeNoPlain words, up to 100 characters, e.g. 8:30am assembly
venueYesRange name and address, up to 200 characters
shoot_typeYesOne of Target, Field, 3D, Indoor, Clout, Other
entry_methodNoOne of archers_diary, iscored, assemble, trybooking, eventbrite, online_form, website, email, day (pay on the day), other (explain in notes)
entry_linkFor online entryFull web address starting with https://
entry_emailFor email entryThe club's entries email address (shown publicly)
entry_close_dateNoYYYY-MM-DD
bank_account_name, bank_bsb, bank_account, bank_referenceNoPayment details for entries (BSB 6 digits, account 4–10 digits)
roundsNoUp to 200 characters
notesNoAnything else archers should know, up to 1000 characters
flyer_urlNoWeb address of the flyer (image or PDF), starting with https://
cancelledNotrue keeps the event listed but marks it Cancelled

Rules: text can't contain < or >, links must be http(s):// web addresses, and any field not in this table is refused. Your club's name and state come from your key, so you don't send them.

4. Delete an event

curl -X DELETE "https://sllsqpfqwckwtljzjxli.supabase.co/functions/v1/club-events?id=2027-field-champs" \
  -H "X-Api-Key: YOUR_CLUB_KEY"

To keep it on the calendar marked as cancelled instead, send it again with "cancelled": true.

5. See what we have for your club

curl https://sllsqpfqwckwtljzjxli.supabase.co/functions/v1/club-events -H "X-Api-Key: YOUR_CLUB_KEY"

6. Responses

Success (HTTP 200):

{
 "ok": true,
 "club": "Your Archery Club",
 "results": [ { "id": "2027-field-champs", "result": "created" } ],
 "page": "https://archerycalendars.com/#/browse"
}

result is created or updated. If anything is wrong, nothing in that call is saved and you get "ok": false with a plain-English reason:

{ "ok": false, "error": "event 1: start_date must be YYYY-MM-DD" }
CodeMeaning
400Something in the event needs fixing (the error says what)
401Key missing, wrong or switched off
404Delete: no event with that id for your club
413Too big (max 64 KB per call)
429Too many calls (max 30 a minute, 600 a day). Wait and try again

Good to know

  • Events usually show on the site within a minute. Archers may need to refresh the page.
  • Please send one call at a time (wait for each answer before the next). Batch several events into one call instead of sending them side by side.
  • Every call is logged (club, time, what changed).
  • Only send real, confirmed events. Questions? Email nfshold@gmail.com.
