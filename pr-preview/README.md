# Pull request previews

A folder named `pr-<number>` here is a temporary copy of that pull request, published so the change can be opened before it is merged.

The live calendar is the rest of this site, at the repository root. Nothing in this folder is linked from the live pages. The preview job removes `pr-<number>` when the pull request is closed.

Open a preview at `https://archerycalendars.com/pr-preview/pr-<number>/`.
